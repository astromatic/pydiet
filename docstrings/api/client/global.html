    fetch_html(selector, url, optionsopt) → {Promise.<boolean>}

    Fetch an HTML fragment and inject it into an element.

    GET data is encoded as query parameters. Any method other than the literal string "get" sends a POST request whose body is data. Request and injection errors are converted to false.

    Parameters

    • selector string

      CSS selector passed to inject_html.

    • url string | URL

      Resource URL.

    • options object <optional>
       {}

      Request options.

      Properties

      • method string <optional>
         'get'

        Request method selector.

      • data * <optional>

        Query values for GET or request body for POST.

    Returns

    • Promise.<boolean>

      true after successful injection; otherwise false.

    Example

    await fetch_html('#results', '/ui/demo/results', {
  data: {brightness: 20, snr: 10}

    plot_filter(filter, atmosphere, canvas, wave_minopt, wave_maxopt) → {void}

    Create an interactive transmission chart.

    The initial wavelength limits come from filter.wave_range; wave_min and wave_max are currently accepted but ignored. Chart.js zooming and panning are enabled, including shift-drag zoom.

    Parameters

    • filter object

      Instrument transmission model.

      Properties

      • name string

        Filter display name.

      • wave Object

        Wavelength samples.

      • response Object

        Transmission samples.

      • wave_range Object

        Initial wavelength limits.

    • atmosphere object

      Atmospheric transmission model.

      Properties

      • wave Object

        Wavelength samples.

      • response Object

        Transmission samples.

    • canvas HTMLCanvasElement | string

      Canvas or canvas ID accepted by Chart.js.

    • wave_min number <optional>

      Currently unused requested lower wavelength.

    • wave_max number <optional>

      Currently unused requested upper wavelength.

    Returns

    • void

    Example

    plot_filter(
  {
    name: 'g',
    wave: {value: [400, 500], unit: 'nm'},
    response: {value: [0.2, 0.8]},
    wave_range: {value: [400, 500]}
  },
  {wave: {value: [400, 500]}, response: {value: [0.9, 0.95]}},
  'transmission-chart'
);
