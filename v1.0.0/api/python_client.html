Query the ETC API.

Parameters:

  • query (ETCQueryModel) -- Validated ETC query. Its instrument field selects the endpoint; the remaining non-null fields are sent as query parameters.

  • timeout (float, optional) -- HTTP timeout in seconds.

Returns:

response (ETCResponseModel) -- Validated ETC response.

Raises:

RuntimeError -- If the request fails, the server returns an error response, the response is not JSON, or its JSON does not match the response model.
